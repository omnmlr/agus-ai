# Reference review

The approved Web Design Core v1.0 includes a brand board, a mascot reference, and contact sheets. The archive supplied contact sheets for Resend, Browserbase and HeyElsa. Those references informed layout and interaction and are kept out of the shipped site.

| Reference | Applied observation |
| --- | --- |
| Approved AGUS AI board | Uppercase Geist lockup, original ghost geometry, neutral light/shadow, semantic accent roles and visible clear space. |
| Resend contact sheet | Product explanation beside a legible code or data artifact, focused CTA, spacious footer. The sheets show the marketing site. |
| Browserbase contact sheet | Fine technical dividers and diagrams with short labels support the build-to-execution and agent traces. The later frames show a blank pane. |
| HeyElsa contact sheet | Varied module rhythm, a developer-facing terminal and an extensive closing section. AGUS uses its own art and product vocabulary. |
| [Linear](https://linear.app/) | Public product UI remains central to the pitch. AGUS shows the actual workspace and separates it from the illustrative execution. |
| [Solana Seeker](https://solanamobile.com/seeker) | Published hardware informs the angle, screen proportions and polished edge treatment of the original Seeker visual. |
| [Teenage Engineering](https://teenage.engineering/products/op-1) and [Polestar](https://www.polestar.com/us/polestar-4/) | Material and silhouette carry much of the first viewport. AGUS lights the two subjects as a single scene. |

Earlier visual research also included Vercel, Stripe, BrowserStack, Raycast, Framer, Sentry, Codrops, and Awwwards. Figma was unavailable through the browser proxy. Atlas Computers results did not identify a matching site with confidence. The repository’s [competition analysis](../research/COMPETITIVE_LANDSCAPE.md) and [customer use cases](../research/CUSTOMER_USE_CASES.md) ground the scope and commercial narrative.

The implementation adopted only written guidance from the Anthropic frontend design, Taste, UI/UX Pro Max, Designer Skills, and Vercel interface guidelines. Browser verification used Chromium, Playwright and the repository’s DevTools acceptance harness.
