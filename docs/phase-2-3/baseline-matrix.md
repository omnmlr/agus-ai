# Original functionality matrix

Baseline `b28f104`. The commercial dossier at `3893024` is part of this branch. The original handoff filenames are referenced by [the checked-in frontend contract](../../FRONTEND_CONTRACT.md). The reference implementations, [historical Chisom handoff](../mobile-test/FRONTEND.md), and [Phase 1 ADRs](../phase-1/README.md) are the functional baseline. GitHub listed only the commercial PR and the Android setup, Phase 1 and main branches at the start. Static wiring and historical evidence below are baseline findings.

| Surface and interactions | Actual implementation and model | Evidence or gap | Dependency or deferral |
| --- | --- | --- | --- |
| Android welcome, sign in, register, email send/verify, invitation review, developer portal, back | `ProviderScreens`, `MainActivity`, person session and `/auth/*`, private invitation code and origin checks | Password preview and OTP UI wired. Native Google sign-in UI missing. | Live email, OAuth and App Links require authorized deployment config. |
| Android enrollment, code copy, status and refresh | `/me/devices/pairings` and owned devices | Dedicated pairing only. Phase 1 separate controller proved work-profile consent on AVD. | Native provision, profile policy, scoped key/lease, qualification and recovery missing in reference app. |
| Android Home, earnings chart link, device link, stats, current session | `ProviderScreens.home`, session/device/earnings collections | Chart link navigates to Earnings. Status and contributions depend on real API data. | Native/campaign state and verified compensation missing. |
| Android My Device and device options | Owned devices, heartbeat, diagnostics, rename, share, revoke | Existing dedicated measurements, device owner checks and lifecycle | Native runtime safety, provenance and qualifiers missing. |
| Android Activity settings | Listing, auto-match, time windows, charging and Wi-Fi through device PATCH | Dedicated resource and ownership checks | Native authorization window with explicit consent missing. |
| Android Activity jobs and history | Marketplace, private requests, running/history lists, inbox and read state | Reviewed offer, private code, accept/decline/revoke and opened run.
